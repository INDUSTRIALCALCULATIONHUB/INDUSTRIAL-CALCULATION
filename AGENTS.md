# Repository Instructions

When creating, modifying, reviewing, or testing any plate-development calculator page in this repository, read and follow [PLATE-DEVELOPMENT-PAGE-RULES.md](PLATE-DEVELOPMENT-PAGE-RULES.md) before editing the implementation.

Treat that file as the shared baseline for plate-development inputs, mid-surface geometry, orthographic views, complete developed patterns, dimensions, DXF, print/PDF, colours, annotations, local review, and acceptance checks. A later explicit instruction from the user overrides the baseline for the affected page.

Do not apply the plate-development rules to unrelated calculator pages.
